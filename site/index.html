The agentic SDLC framework · for Claude Code · Apache-2.0

AI colleagues build.
Guards prove. You decide.

C.R.I.S.S.P. turns one repository into a team. AI colleagues plan, build, review and test your product with you. Guards prove every change. You, the product owner, decide what gets built, what is accepted and what goes live. The whole software lifecycle runs in plain files next to the code.

uvx crissp init

Python 3.12+, git and bash. The engine uses only the Python standard library.

Your AI colleagues

A team with clear jobs, and clear limits.

None of them can declare its own work done, and none of them can release. That stays with you.

Lead

Claude, your main session

Reads the agreement first, keeps the backlog, builds test-first, hands parts to agents, reviews and merges their work, runs the checks, writes the release notes and reports to you per item.

Never pushes, deploys or publishes without your yes.

Builders

Agents

One part each (a backend, a frontend, a chart) in their own git worktree. They write the failing test first, make it green, run their part's suite and report.

Never edit the backlog, the release notes or secrets.

UX team

Five personas and a moderator

An engineer, someone who rarely uses a computer, a student on a phone, a product owner and a UX expert walk your running product, debate it and advise: must, should, could.

Advise only: their advice waits for your verdict.

Designer

Designs on request

A mockup of the screen after the advice, shown next to the screen as it is now. Approve it, with a remark if you like, and it becomes a backlog item.

A design is a proposal, never a change.

MCP

The crissp tool

The team's shared memory and hands: it answers Claude with exactly the lines it needs, writes the backlog in its own format under the next free number, and starts the checks.

Never deploys, never marks work done.

You

The product owner

You take the decisions (each comes with options and a recommendation), ask for UX rounds, accept work, push and deploy. Every change to production asks you y/N.

The only one who moves work to done.

The agentic SDLC

From the first observation to the release that delivered it.

See it

One local dashboard for the tests, the board and the UX team.

A demo project made with crissp init: its backlog, test run and screenshots are real; the UX round's and the design's text is a sample (a real round runs on your own Claude login).

The six letters

Six promises, each with something that checks it.

C

Consistent

One way, everywhere: the same files, formats and words in every repository.

Checked by the formats and review

R

Repeatable

A test that fails without the fix, scripted checks and deploys, and a certificate for exactly one commit.

Checked by crissp check and the certificate

I

Innovative

Every observation is written down at once. Decisions come as options with a recommendation. Virtual users debate the interface before real ones meet it.

Checked by findings, decisions and the UX suite

S

Secure

Secrets never in git, an image, a log or a chat. Every change to production asks first.

Checked by ignore rules, security tests and the y/N

S

Scalable

Small steps that add up: work that fits one commit, agents per part, tests that run what a change can affect.

Checked by sizes, the impact plan and worktrees

P

Programming

Done means done: one commit per item, coverage only goes up, release notes always.

Checked by the definition of done and the coverage gate

What you get

One package. Everything a repository needs to work this way.

MCP

The crissp tool

Claude asks for the lines it needs instead of reading whole files: brief, backlog. It writes findings, decisions, epics, features and items in the backlog's own format, and starts the checks. It never deploys and never marks work as done.

Guards

Check, gate, certificate

The impact plan tests what a change can affect; the full run tests everything; the coverage gate only goes up; the certificate names the commit that was proven.

Dashboard

Tests and the board

What the last runs proved, the coverage per suite, and the backlog board, on one local server. It never runs a test.

UX suite

People who are not us

Fictional users walk your running product on a laptop and a phone, debate it, and a moderator turns it into advice. An approved design becomes a backlog item.

Deploy

Helm and Terraform

A chart for a backend, a frontend and PostgreSQL with a nightly backup, behind Traefik: non-root, read-only, with NetworkPolicies. Terraform for the cluster side.

Template

The agreement and the backlog

How your product is built, tested, released and run, read first in every Claude session, with a backlog in plain Markdown next to the code.

No bypass

The release gate has no switch to turn it off, and Claude never builds one.

A person decides

Claude builds, proposes and reports. The product owner accepts, pushes and deploys.

Secrets stay secret

Never in git, an image, a log or a chat. Only their presence is ever printed.

Local first

The dashboard and the UX suite run on 127.0.0.1 and load nothing from the internet.

Get started

Four steps to a project that proves itself.

1

Bring a folder in

mkdir my-product && cd my-product
uvx crissp init --product "My product"

In an existing repository it adds only what is missing and never overwrites a file.

2

Fill it in with Claude

claude

Ask it to fill in the <!-- CRISSP: … --> blocks: your parts, your tests, your deploy.

3

Review and commit

git diff
git add -A && git commit -m "CRISSP: adopt C.R.I.S.S.P."

Nothing is committed before you have seen it.

4

Prove it

crissp check-all
crissp dashboard

The full run, then what it proved, on your own machine.

CommandWhat it does
crissp initBrings a folder in: git init, the agreement, the backlog, the configuration, the deploy template
crissp check [--plan]Runs only what the changes since the last green state can affect
crissp check-allThe full run, with the coverage gate
crissp deploy [--cluster]Deploys behind the release gate; --cluster-plan only shows what it would do
crissp dashboardThe Tests dashboard, the backlog board and the UX suite on 127.0.0.1
crissp uxThe UX suite: walks, rounds, designs
crissp mcpThe MCP server Claude Code starts from .mcp.json
